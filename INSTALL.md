# Installing KDC Cam on your Android phone

KDC Cam isn't on the Play Store — you install it from a file (an "APK"). It takes
about a minute. **iPhone is not supported.**

## 1. Download the app

1. On your Android phone, open this link:
   **https://github.com/ianpogi5/kdc-cam/releases/latest**
2. Under **Assets**, tap the file ending in **`.apk`** to download it.
3. If the browser asks "keep / download anyway?", choose to keep it — the file
   is safe.

## 2. Open the file

Open the downloaded file (tap the download notification, or find it in your
**Files** app under **Downloads**).

## 3. Allow installing this one app

The first time, Android will say it can't install apps from this source. This is
normal for apps outside the Play Store.

1. Tap **Settings** on that pop-up.
2. Turn on **Allow from this source** (your browser or Files app).
3. Go **back** — the install screen appears.

## 4. Install

1. Tap **Install**.
2. If "Play Protect" warns about an unknown app, tap **More details → Install
   anyway** (or **Scan app** then install). It's flagged only because it's not
   from the Play Store.
3. Tap **Open**.

## 5. Grant permissions

On first launch, tap **Allow** for **camera, microphone, location, and photos** —
the app needs them to record stamped photos/videos and save them to your gallery.

That's it! 🎉

## Updating later

When a new version is released, just repeat steps 1–4 with the new APK — it
installs over the old one and keeps your settings. (No need to uninstall.)
